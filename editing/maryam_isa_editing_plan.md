## 🎵 خطة الموسيقى (Music Plan)

### الليتموتيفات (Leitmotifs) — 6 ثيمات رئيسية

| الثيم | الاسم | الآلات | الاستخدام |
|---|---|---|---|
| **A** | **FAITH** (الإيمان) | ناي + كمان سولو + وتر خفيف | مشاهد مريم، المحراب، الدعاء، السلام |
| **B** | **MIRACLE** (المعجزة) | قانون + ناي + جرس خفيف + وتر دافئ | كل معجزة: رزق، مخاض، كلام المهد، طير، شفاء، إحياء، مائدة، رفعة |
| **C** | **STRUGGLE** (الابتلاء) | تشيللو منخفض + دف بطيء + وتر متوترة | مخاض، اتهام، مكيدة، صلب (شبه) |
| **D** | **DIVINE** (التدبير الإلهي) | كورال ذكور منخفض + ناي باس + طبول عميقة | "مكروا ومكر الله"، الرفعة، النزول، يوم القيامة |
| **E** | **INNOCENCE** (البراءة/الطفولة) | قانون عالي + بيانو ناعم + جرس | مشاهد مريم طفلة، الرضيع، البراءة |
| **F** | **UNITY** (الوحدة/التوحيد) | آلات كاملة: وتر + ناي + قانون + دف + كورال | الخاتمة، الكعبة، الآية الأخيرة |

## ✂️ خطة الانتقالات (Transitions Plan)

### أنواع الانتقالات المستخدمة

| النوع | الكود | الاستخدام | المدة |
|---|---|---|---|
| **Hard Cut** | `CUT` | بين مشاهد نفس الفصل، تغيير زاوية | 0 إطار |
| **Match Cut** | `MATCH` | تشابه بصري/موضوعي (يد→يد، نور→نور) | 0 إطار |
| **Audio Bridge** | `A-BRIDGE` | الصوت يسبق الصورة أو يستمر | 1-2ث overlap |
| **Fade to Black** | `FTB` | فواصل فصلية كبرى، "سنوات لاحقة" | 1.5-2ث |
| **Cross Dissolve** | `DISSOLVE` | ذكريات، رؤى، انتقال زمني ناعم | 1.5-2ث |
| **Light Flash** | `FLASH` | أحداث معجزية، لحظة الوحي | 0.5-1ث |
| **Iris/Wipe** | `NEVER` | لا تستخدم (قديمة) | — |

### سير العمل للتلوين (Grading Workflow)
```
1. Primary Correction (لكل كليب):
   - Exposure, White Balance, Contrast
   - Match شوتات نفس المشهد

2. Secondary (لون محدد):
   - Skin tones محمية (Vector scope)
   - Sky/Background منفصل
   - Key light sources معزولة

3. Creative LUT (فصلي):
   - Apply LUT عند 50-70% opacity
   - تعديل حسب الكليب

4. Global (على التايملاين كامل):
   - Film grain خفيف (35mm style)
   - Vignette خفيف جداً على المشاهد الحميمة
   - Letterbox للـ 2.39:1 اختياري (للسينمائية)

5. QC Final:
   - Waveform: لا قص في Whites/Blacks
   - Vectorscope: Skin tones على Skin tone line
   - Loudness: -14 LUFS
```

# PHASE 8: VOICEOVER PRODUCTION GUIDE — مريم وعيسى
*دليل تسجيل السرد الصوتي العربي — جودة بث احترافية*

## 🎙️ مواصفات الراوي المثالي (Narrator Profile)

| المعيار | المواصفة |
|---|---|
| **الجنس** | ذكر (صوت ذكوري دافئ، تقليدي) |
| **العمر الصوتي** | 35-50 سنة (نضج، حكمة، ليس شيخاً، ليس شاباً) |
| **اللهجة** | مغربية عربية فصحى مبسطة — نطق صحيح للحروف العربية، خاصة: <br>• **ض** (مطبق) <br>• **ظ** (مطبق) <br>• **ق** (قاف بدوية/مصرية = ج، أو قاف قياسية) <br>• **ث، ذ، ظ** محققة <br>• **الهمزات** محققة |
| **النبرة (Tone)** | • **دافئ** (Warm) — كأنك تحدث ابن أخيك<br>• **بشري** (Human) — ليس مذيع أخبار، ليس خطيب منبر<br>• **وقور** (Dignified) — احترام للموضوع<br>• **متنوع** — يتسع للهمس، التصاعد، السكون |
| **السرعة** | 150-160 كلمة/دقيقة (أبطأ من المحادثة، أسرع من التلاوة) |
| **الإيقاع** | طبيعي، مع وقفات ذات معنى — ليس "مترونوم" |

### مراجع صوتية (للاستلهام فقط — لا تقليد)
- **أسلوب الراوي في الوثائقيات العربية الرصينة** (مثل: الجزيرة الوثائقية، وثائقيات التاريخ)
- **قراءة القرآن بخشوع** — لكن بسرعة كلام، ليست ترتيلاً
- **الحكواتي التقليدي** — لكن بمعاصرة، بلا مبالغة

## 🎚️ إعداد التسجيل (Recording Setup)

### المعدات الدنيا (Minimum Viable)
| العنصر | المواصفة | بديل اقتصادي |
|---|---|---|
| **ميكروفون** | Large Diaphragm Condenser (Cardioid) — مثل: Audio-Technica AT2035, Rode NT1-A, Lewitt LCT 440 | USB Mic: Blue Yeti, Fifine K669B |
| **واجهة صوتية** | Focusrite Scarlett 2i2, Audient iD14 | غير مطلوب مع USB Mic |
| **سماعات** | مغلقة (Closed-back) — Audio-Technica ATH-M50x, Sony MDR-7506 | أي سماعة مغلقة جيدة |
| **برنامج تسجيل** | Audacity (مجاني)، Reaper (تجريبي غير محدود)، OBS | Audacity كافٍ |
| **معالجة الغرفة** | بطاطين، وسائد، ملابس — امتصاص صدى | خزانة ملابس مفتوحة، تحت بطانية |

### إعدادات التسجيل التقنية
| الإعداد | القيمة |
|---|---|
| **Sample Rate** | 48 kHz (معيار الفيديو) |
| **Bit Depth** | 24-bit |
| **Channels** | Mono |
| **Gain Staging** | Peak عند -12 dBFS إلى -6 dBFS (لا يتجاوز -3 dBFS) |
| **High-Pass Filter** | 80-100 Hz (على الميكروفون أو في الطرح) |
| **Noise Floor** | أقل من -60 dBFS (هدوء تام) |

### بيئة التسجيل (Room Treatment)
```
✅ افعل:
- سجل في خزانة ملابس مملوءة (أفضل "استوديو" منزلي)
- أغلق النوافذ، أطفئ المكيف/المراوح
- ضع الميكروفون بعيداً عن الجدار (30-50 سم)
- استخدم Pop Filter (أو جورب نظيف على الميكروفون)
- اجلس/قف بثبات — لا تتحرك أثناء التسجيل

❌ لا تفعل:
- تسجل في غرفة فارغة (صدى)
- تقترب كثيراً من الميكروفون (proximity effect مفرط)
- تلمس الميكروفون أو الكابل
- تتنفس مباشرة في الميكروفون
- تسجل لجلسات طويلة دون راحة (إرهاق صوتي)
```

## 📖 دليل الأداء (Performance Guide)

### علامات الإخراج — كيف تؤدي كل واحدة

| العلامة | التعليمات الأدائية | مثال من السيناريو |
|---|---|---|
| **[همس]** | • خفّض الصوت لـ 30-40%<br>• اقترب من الميكروفون (10-15 سم)<br>• اجعل التنفس مسموعاً قليلاً<br>• نبرة حميمة، سرية | "طفلٌ في المهد... يتكلم." |
| **[إيقاف]** | • توقف **تام** لـ 1.5-2 ثانية<br>• لا تتنفس بصوت مسموع<br>• احتفظ بالطاقة الداخلية<br>• العينان تتحركان كأنك تقرأ صورة | بعد "طفلٌ في المهد... يتكلم." |
| **[بطيء]** | • مدد الحروف قليلاً<br>• وزن كل كلمة وكأنها حجر كريم<br>• نبرة جادة، غير مستعجلة | "كلمة الله... وروح منه." |
| **[عاطفي]** | • ادخل في المشاعر حقاً<br>• صوت قد يرتجف قليلاً<br>• أبطئ قليلاً<br>• دفء في الصدر ينعكس في الصوت | "كلمة أم... في لحظة ضعف بشري." |
| **[تصاعد]** | • ابدأ معتدل، ازدد قوة تدريجياً<br>• ليس صراخاً — قوة داخلية<br>• الصدر يتوسع، التنفس أعمق<br>• تصل لذروة في آخر الجملة | "مكروا هم... وقتلوا هم... وصلبوا هم..." |
| **[سكون]** | • بعد العاصفة — هدوء عميق<br>• صوت منخفض، بطيء، مستقر<br>• حكمة، ليس حزناً<br>• مساحة بين الكلمات | "رفعه الله إليه. حياً. بجسده وروحه." |
| **[سؤال بلاغي]** | • نبرة استفهام حقيقية<br>• ارتفع قليلاً في نهاية السؤال<br>• **انتظر 2-3 ثوانٍ** بعد السؤال (مهم!)<br>• كأنك تنتظر إجابة المشاهد | "أليست العبودية الحقّة... هي أسمى درجات الحرية؟" |
| **[اقتباس]** | • غيّر النبرة قليلاً — "صوت النص"<br>• أبطأ، أوضح، أكثر رسمية<br>• كأنك تقرأ من مصحف/كتاب<br>• رجوع للنبرة العادية بعد الاقتباس | الآيات والأحاديث |

## 🎯 نصائح عملية للتسجيل

### قبل التسجيل (Pre-Session)
1. **اقرأ السيناريو كاملاً** بصوت عالٍ مرة واحدة — افهم التدفق
2. **حدد أماكن التنفس** — ضع علامة `/` حيث ستتنفس طبيعياً
3. **مرر على الآيات/الأحاديث** — تدرب على نبرة [اقتباس] المميزة
4. **اشرب ماء دافئ** — لا بارد، لا كافيين، لا ألبان
5. **تمارين صوتية 5 دق** — همهمات، شفاه مترددة، مقياس صغير

### أثناء التسجيل (During Session)
```
تقنية "Punch and Roll" للتصحيح الفوري:
1. سجل فقرة كاملة
2. إذا أخطأت: توقف، ارجع 3-5 ثوانٍ قبل الخطأ
3. اضغط تسجيل مجدداً (Punch in)
4. استمر — ستحذف الجزء الخاطئ في التحرير
```
**مهم:** لا تتوقف لكل كلمة. سجل **بمقاطع منطقية** (فصل/مشاهد).

### ترتيب التسجيل المقترح (للحفاظ على الطاقة)
1. **المقدمة + الخاتمة** (أعلى طاقة، تحدد النبرة)
2. **الفصول العاطفية القوية** (3، 4، 5، 8، 9) — وأنت طازج
3. **الفصول السردية الهادئة** (1، 2، 6، 7) — طاقة متوسطة
4. **الآيات/الأحاديث المنفصلة** — يمكن تسجيلها دفعة واحدة بنبرة [اقتباس]

### بعد التسجيل (Post-Session)
- [ ] استمع للتسجيل كاملاً مرة واحدة
- [ ] علّم المواضع التي تحتاج إعادة (Pickups)
- [ ] سجل الـ Pickups في نفس الجلسة أو اليوم التالي (نفس الإعداد)
- [ ] صدّر الملفات بصيغة **WAV 48kHz/24bit** (لا MP3)

## 🔧 معالجة ما بعد التسجيل (Post-Processing Chain)

### سلسلة المعالجة المقترحة (بترتيب التطبيق)

| المعالج | الإعدادات | الغرض |
|---|---|---|
| **1. High-Pass Filter** | 80-100 Hz, 12 dB/oct | إزالة رجة الترددات المنخفضة |
| **2. Noise Reduction** | Light (RNNoise أو iZotope RX) | إزالة ضوضاء الأرضية فقط |
| **3. De-Esser** | Threshold: -25 dB, Range: 6 dB | تهدئة الصافرات (س، ش، ز) |
| **4. EQ (تصحيحي)** | Cut: 200-400 Hz (-2 إلى -4 dB) إذا طيني<br>Boost: 3-6 kHz (+1 إلى +2 dB) للوضوح<br>Cut: >12 kHz برفق | توازن نغمي |
| **5. Compression** | Ratio: 3:1 إلى 4:1<br>Attack: 10-30 ms<br>Release: 50-100 ms<br>Threshold: -18 إلى -24 dB<br>Gain Reduction: 3-6 dB max | تماسك الديناميك |
| **6. Limiter** | Ceiling: -1 dBTP<br>True Peak detection | أمان نهائي |
| **7. Loudness Normalization** | Target: -14 LUFS (YouTube)<br>True Peak: -1 dBTP | معيار البث |

### أدوات مجانية للمعالجة
- **Audacity**: كل ما سبق متاح (Built-in + Plugins)
- **Reaper**: JS Plugins ممتازة (ReaEQ, ReaComp, ReaFIR, ReaGate)
- **iZotope RX Elements** (إذا متاح): De-noise, De-click, De-hum احترافية

## 🎵 دليل المكس النهائي (Final Mix Guide)

### مستويات الصوت في التايملاين (Timeline Levels)
| المسار | المستوى (dB) | ملاحظات |
|---|---|---|
| **Voiceover** | 0 dB (Reference) | لا يلمس بعد الماسترنج |
| **Music** | -18 إلى -22 dB | Ducking تحت السرد |
| **Foley/SFX** | -12 إلى -18 dB | لحظات فقط |
| **Ambience** | -24 إلى -30 dB | طبقة خلفية خفيفة |

### Ducking للموسيقى (Sidechain Compression)
- **Trigger**: Voiceover track
- **Target**: Music track
- **Ratio**: 4:1 إلى 6:1
- **Attack**: 10 ms
- **Release**: 200-500 ms (طبيعي)
- **Threshold**: -20 dB
- **Gain Reduction**: 6-12 dB عند الكلام

### التحقق النهائي (Final QC)
- [ ] **Loudness**: -14 LUFS ±0.5 (YouTube) / -16 LUFS (Podcast)
- [ ] **True Peak**: ≤ -1 dBTP
- [ ] **LRA** (Loudness Range): < 8 LU (للحديث)
- [ ] **لا قص** (Clipping) في أي نقطة
- [ ] **لا ضوضاء** مسموعة في فترات الصمت
- [ ] **المزامنة**: الصوت يتطابق مع الصورة (Lip-sync غير مطلوب، لكن التوقيت نعم)
- [ ] **السربتايتل**: متزامنة مع الصوت

## 🎤 خيارات بديلة: TTS (Text-to-Speech)

إذا تعذر تسجيل بشري، أفضل الخيارات الحالية:

| الأداة | الجودة | التكلفة | دعم العربية |
|---|---|---|---|
| **ElevenLabs** (Multilingual v2) | ⭐⭐⭐⭐⭐ | $22/شهر | ممتازة، صوت "Ahmed" أو "Hassan" |
| **XTTS-v2** (Coqui, محلي) | ⭐⭐⭐⭐ | مجاني (GPU) | جيدة، تحتاج fine-tuning |
| **Azure TTS** (Neural) | ⭐⭐⭐⭐ | Pay-per-use | صوت "Naasih" أو "Zariyah" |
| **Google Cloud TTS** (Neural2) | ⭐⭐⭐⭐ | Pay-per-use | صوت "ar-MA-Standard-A" |
| **OpenVoice** / **CosyVoice** | ⭐⭐⭐ | مجاني (محلي) | واعدة، حديثة |

### نصائح TTS للجودة القصوى
1. **قسّم النص** جملاً قصيرة (أقل من 200 حرف)
2. **أضف علامات SSML** للوقف، السرعة، النبرة:
```xml
<speak>
  <prosody rate="90%">طفلٌ في المهد... يتكلم.</prosody>
  <break time="1500ms"/>
  <prosody rate="85%" pitch="-2st">ليس بغناء، ولا لهو.</prosody>
</speak>
```
3. **ولّد 3-5 تنويعات** لكل فقرة، اختر الأفضل
4. **عدّل يدوياً** في Audacity: timing، breathing، energy
